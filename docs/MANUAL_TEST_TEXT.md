# Паспортный тестовый текст ReTypeR — v1.3 regression corpus

Полный корпус для ручной проверки умной конвертации раскладки. Унаследован от
корпуса v1.2: все 10 блоков сохранены дословно и служат regression corpus
релиза v1.3. Ручные релизные сценарии v1.3 — в разделе
«[v1.3 release checklist](#v13-release-checklist)» в конце файла; все их статусы
PENDING до фактического прогона.

## Как пользоваться

1. Убедитесь, что в настройках ReTypeR выбрана пара раскладок **US / Русский — Windows**
   (или ваша обычная пара) и включено **«Умное распознавание раскладки»**.
2. Скопируйте блок «Вставьте это» в любой текстовый редактор.
3. Выделите текст и нажмите горячую клавишу конвертации (по умолчанию `⌃⇧Space`).
4. Сравните результат с блоком «Должно получиться».

> Примечание: в блоках ниже обратный апостроф `` ` `` — это клавиша «ё»
> (тильда в английской раскладке).

## 1. Короткие слова и предлоги (классическая проблема)

**Вставьте это:**

```
f jyj to` b yt hf,jkjtj
```

**Должно получиться:**

```
а оно ещё и не работало
```

## 2. Полный набор предлогов и союзов

**Вставьте это:**

```
d ktce e htrb pf ljvjv
```

**Должно получиться:**

```
в лесу у реки за домом
```

**Вставьте это:**

```
b z ei`k ,s ljvjq yj yt cvju
```

**Должно получиться:**

```
и я ушёл бы домой но не смог
```

## 3. Буква «ё» и «Ё»

**Вставьте это:**

```
`;br b `krf
```

**Должно получиться:**

```
ёжик и ёлка
```

**Вставьте это:**

```
~krf dshjckf
```

**Должно получиться:**

```
Ёлка выросла
```

## 4. Оба направления и регистр

**Вставьте это (набрано в английской раскладке):**

```
Ghjdthbv Ntcn
```

**Должно получиться:**

```
Проверим Тест
```

**Вставьте это (набрано в русской раскладке):**

```
руддщ цщкдв
```

**Должно получиться:**

```
hello world
```

## 5. Смешанный текст: правильное остаётся, опечатка исправляется

**Вставьте это:**

```
Привет, ghbdtn! How дела?
```

**Должно получиться:**

```
Привет, привет! How дела?
```

## 6. Ссылки (URL) не должны ломаться

**Вставьте это (правильный текст с URL):**

```
Зайди на https://example.com/page?id=42 и скажи мне
```

**Должно получиться (без изменений):**

```
Зайди на https://example.com/page?id=42 и скажи мне
```

**Вставьте это (URL, набранный не в той раскладке):**

```
реезы://учфьзду.сщь
```

**Должно получиться:**

```
https://example.com
```

## 7. E-mail не должен меняться

**Вставьте это:**

```
Пиши на test@mail.ru сегодня
```

**Должно получиться (без изменений):**

```
Пиши на test@mail.ru сегодня
```

## 8. Код и идентификаторы не должны меняться

**Вставьте это:**

```
let result = my_variable + 12; версия 1.2.0 и патч v2
```

**Должно получиться (без изменений):**

```
let result = my_variable + 12; версия 1.2.0 и патч v2
```

## 9. Правильный текст обязан остаться нетронутым

**Вставьте это:**

```
Правильный русский текст не должен меняться.
Correct English text must stay unchanged.
```

**Должно получиться (без изменений):**

```
Правильный русский текст не должен меняться.
Correct English text must stay unchanged.
```

## 10. Числа, даты и спецсимволы

**Вставьте это:**

```
Заказ №123 от 05.08.2026 — подтверждён
```

**Должно получиться (без изменений):**

```
Заказ №123 от 05.08.2026 — подтверждён
```

## Что покрывает этот корпус

| № | Признак |
|---|---|
| 1 | Однобуквенные слова и короткие предлоги («а оно ещё») |
| 2 | Полный набор предлогов/союзов/частиц (в, у, за, и, бы, но, не…) |
| 3 | Буквы «ё»/«Ё» (клавиша `` ` `` / `~`) |
| 4 | Оба направления конвертации + заглавные буквы |
| 5 | Смешанные RU/EN предложения |
| 6 | Защита URL (правильных) и починка URL в неверной раскладке |
| 7 | Защита e-mail |
| 8 | Защита кода, версий и идентификаторов (`_`, буквы+цифры) |
| 9 | Безопасный дефолт: корректный текст не портится |
| 10 | Числа, даты, № и спецсимволы |
