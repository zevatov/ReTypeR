# ReTypeR — Регламент и пайплайн разработки для AI-агентов

> **Статус:** Обязательный регламент (Pipeline Regulations) для всех AI-ассистентов, работающих с репозиторием ReTypeR.
> **Актуальная версия:** 1.3.5 (build 6).
> **Дата утверждения:** 2026-09-28.

---

## 1. Каноническая архитектура сборки

1. **XcodeGen как единственный источник истины:**
   - Структура проекта, таргеты, зависимости и версии определяются строго в [`project.yml`](../project.yml).
   - Файл `ReTypeR.xcodeproj` генерируется автоматически командой `xcodegen generate` и **никогда не коммитится в git**.
   - Не редактируйте `.xcodeproj` через скрипты или вручную. Все настройки добавляются только в `project.yml`.

2. **Формат и именование артефактов:**
   - Имена бандла и пакета дистрибутива строго фиксированы **без номеров версий в названиях**:
     - Приложение: `ReTypeR.app`
     - Инсталлятор: `ReTypeR.dmg`
   - Это гарантирует предсказуемую замену в `/Applications` без накопления дубликатов и стабильный URL для релизов:
     `https://github.com/zevatov/ReTypeR/releases/latest/download/ReTypeR.dmg`.

3. **Кодовая подпись и безопасность:**
   - Сборка подписывается персональным сертификатом `Apple Development` (`Team 3ZMM724J2P`) с включённым `Hardened Runtime` (`ENABLE_HARDENED_RUNTIME: YES`).
   - Ad-hoc подписи запрещены — они сбрасывают выданные пользователем разрешения Accessibility при каждом перезапуске.

## 2. Железные правила разработки (Iron Rules)

1. **Запрет на возврат OCR в продакшен:**
   - Продуктовый OCR (распознавание текста с экрана) удалён из продакшена 2026-09-14.
   - Запрещено возвращать захват экрана, ScreenCaptureKit, CLI `screencapture` для распознавания текста.
   - Класс C и перечисление `ConversionSource.ocr` в [`SmartScorer.swift`](../Sources/Core/SmartScorer.swift) сохранены исключительно как внутренний scoring-флаг.

2. **Запрет на внесение PII:**
   - Никаких персональных адресов электронной почты, телефонов и личных данных владельца в коде, логах, коммитах или документации.

3. **Запрет на самовольное изменение версий:**
   - Версия приложения (`MARKETING_VERSION` и `CURRENT_PROJECT_VERSION` в `project.yml`) повышается только по прямому указанию владельца.

4. **Запрет на внедрение внешних токенов:**
   - Клиентское приложение не должно содержать GitHub Personal Access Token. Все проверки обновлений используют публичные эндпоинты или открытые релизы.

## 3. Обязательный цикл внесения изменений (The Verification Gate)

Любое изменение кода должно следовать строгому алгоритму:

```
[Изменение кода] → [xcodegen generate] → [xcodebuild test (61/61)] → [build_dmg.sh] → [git commit] → [Obsidian Sync]
```

### Шаг 1. Верификация тестов
Перед фиксацией любых правок обязателен прогон полного набора тестов:
```bash
xcodegen generate && xcodebuild test -project ReTypeR.xcodeproj -scheme ReTypeR -destination 'platform=macOS'
```
**Критерий успеха:** `** TEST SUCCEEDED **` и `Executed 61 tests, with 0 failures`. Ни один тест не должен падать.

### Шаг 2. Сборка DMG-инсталлятора
Каждый релизный цикл сопровождается сборкой пакета через канонический скрипт:
```bash
scripts/build_dmg.sh
```
Скрипт автоматически:
- Собирает конфигурацию Release.
- Подписывает приложение сертификатом разработчика.
- Генерирует подложку высокого разрешения (1320×960 Retina) со ссылками на репозиторий и Telegram.
- Создаёт `ReTypeR.dmg` через `dmgbuild` с правильными позициями иконок (180, 240) и (480, 240).
- Назначает кастомную иконку на файл дистрибутива через `set_dmg_icon.swift`.

```bash
python3 /Users/stanislav/AI_NOTES/3_Sources/Scripts/vault_hygiene_check.py
```
**Критерий успеха:** 7/7 тестов PASS (100% S-TIER).
